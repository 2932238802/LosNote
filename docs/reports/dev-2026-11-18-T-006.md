## 7. 偏差与假设

- `[偏差]` L3 使用 `docker compose up -d --build --force-recreate`，比任务原文多 `--force-recreate`。原因：AC-002-4 要求 `StartedAt` 晚于本次构建开始，AC-002-9 要求无新提交时第二次仍能完成；不强制重建时 compose 可能复用旧容器导致 L4 误判。建议 Doc 记录为新决策（如 D-xxx）。
- `[偏差]` 容器未运行时使用 `docker compose run -T --rm --no-deps ... losnote` 挂载服务定义的数据卷，而不是硬编码 `-v losnote-data:/data`。原因：`docs/deploy.md` 记录实际卷名为 `losnote_losnote-data`（compose 项目前缀），硬编码会挂错卷；compose 自己解析卷名。
- `[假设]` `/data/losnote.db` 不存在时视为首次部署，跳过备份并继续；这不属于“备份失败”，因为没有数据可备份。
- `[假设]` `update.sh` 在本次拉取中变化时只警告，不自动 re-exec；避免旧进程状态与锁复杂度。已在 L1 输出提示“完成后再运行一次”。
- `[未做]` 未更新 `docs/CHANGELOG.md`：本轮指令明确“不要修改 `docs/` 其它文件”。建议 Doc 在统一更新状态时补一条 CHANGELOG。
