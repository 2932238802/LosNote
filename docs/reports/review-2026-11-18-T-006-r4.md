## 4. 缺陷清单（仅 P3，非阻塞）

### [P3] worker 子进程继承锁 fd，孤儿 docker/git 子进程可在 worker 退出后继续持锁

- 位置：`update.sh:157-181`
- 问题：worker 的 docker/git 子进程继承 fd 9；若 worker 在长命令中退出/被杀，孤儿子进程仍持锁；下一次执行提示“已有另一个”，实际没有 update worker。
- 影响：重试被阻塞直到子进程退出/被清理；提示有误导性。不会并发，不会删数据。
- 证据：假 docker 后台 `sleep 60` 继承锁 fd；worker/wrapper 退出后锁仍被持有，第二实例 exit 1（0 次 compose version）；杀掉子进程后锁释放。
- 建议：接受 trade-off 并在提示/文档说明；T-008 观察真实 docker 子进程生命周期。

### [P3] 外部 `LOSNOTE_UPDATE_LOCKED=1` 仍可跳过整个 wrapper

- 位置：`update.sh:111`、`:176-177`
- 问题：仍是唯一重入判据；外部可设置该变量跳过锁。worker 已 unset，子进程继承已阻断；帮助已标注内部，但外部绕过仍存在。
- 建议：随机 nonce + 锁文件内容校验，或校验父进程确为持锁者；至少保持 unset/帮助标注，文档明确。

### [P3] `/run/lock` 与 `$HOME/.cache` 逐候选回退，极端情况下两个实例可能选择不同锁文件

- 位置：`update.sh:113-165`
- 问题：候选失败时逐项回退；两个实例看到不同候选状态时可能用不同锁文件，互不排斥。
- 建议：先确定唯一锁基目录（不可用统一 home cache），不要逐候选回退；T-008 确认锁路径一致。

### [P3] 文档/决策未同步 r4 的锁实现与依赖

- 位置：`AGENTS.md:75`、`docs/deploy.md:196`、`05-decisions`、`04-tasks`、`CHANGELOG`
